# 外贸 Agent 工作台实施计划

状态：阶段一领域规则已完成，阶段二至四待实施。本文不代表界面、登录、数据库或真实模型已完成。

本轮验证：新增领域测试 52 项、原 CRM 回归 44 项全部通过；Python 编译、原前端 JavaScript 语法与 Git 差异检查通过。未启动新服务，未进行新界面浏览器验收，未迁移真实数据。

## 目标与边界

- 一个网站、同一后端；业务员入口与管理入口按角色展示，每个接口独立鉴权。
- 服务内部员工，不向外部买家提供客户名单、地址或内部报价。
- 保留现有 CRM 和 Markdown 数据；当前开发副本没有真实客户数据。
- 客户问数走确定性工具；产品解释走只读 Wiki 检索；金额由结构化数据和 Decimal 计算。
- 模型预选 qwen3.8-max，但本阶段不接 API、不发送数据、不产生模型费用。
- 不自动发送邮件，不让模型直接写 SQL、修改权限或覆盖知识文件。

## 阶段一：契约、领域规则与反例测试

本轮交付，不接入现有运行入口。

- 独立 agent_core 包：角色上下文、客户只读工具、报价版本选择、管理规则修改。
- 身份上下文只能来自未来认证层，不能来自模型的工具参数。
- 固定工具：count_customers、search_customers、get_customer_detail、get_current_price。
- 校验工具名、参数字段及类型；模型不能指定用户、组织、SQL、查询时间或权限。
- 返回结构化事实、状态、来源、时间与政策版本，不以自然语言替代事实字段。
- 价格必须匹配产品、规格、币种、计价单位、贸易条款、数量和客户范围。
- 先排除未批准与未来生效版本，再选择同范围最新已发布版本。
- 最新已发布版本过期或撤回时禁止悄悄回退旧价；没有新有效价就要求复核。
- 重叠数量档位、并列版本、来源不完整或替代关系异常必须关闭报价能力。
- 时效年份与复核周期可配置；历史价格不填入 currentPrice。
- 原有 CRM 44 项回归必须保持通过，新增规则用合成数据验收。

验收：该阶段证明领域规则可运行，不证明登录、数据库持久化、自然语言理解或前端联调已完成。

## 阶段二：PostgreSQL、身份与服务集成

- PostgreSQL 保存员工、角色、客户归属、报价版本、政策版本、任务与审计。
- 先导出备份、只读盘点和 dry-run 报告，明确归属后才切换；不自动迁移真实资料。
- 明确单一客户主源，不能长期无协议地双写 Markdown 和数据库。
- 未分配归属的历史客户只进入管理员待分配列表，不能自动分给所有业务员。
- 登录口令使用标准密码哈希；会话失效、退出、CSRF/跨域策略及限流一并测试。
- 所有旧列表、详情、CSV、创建和编辑接口也必须纳入权限，不能只保护新 Agent 接口。
- 数据库运行账号不能使用超级用户；预编写参数化查询，必要时增加 RLS、只读事务与超时。
- policy 使用版本号并发控制，报价审批、替代与审计在事务中提交。
- 报价金额使用 NUMERIC/Decimal，日期明确采用业务时区，日期截止为左闭右开区间。

验收：业务员不能读其他员工数据或修改政策；修改归属后旧会话不能继续凭缓存越权。

## 阶段三：一个站点的双角色界面

- 保留现有米白、深墨绿、琥珀视觉，不重写已有客户录入与解析功能。
- 业务员：客户工作台、受控问数、当前报价、历史参考、复核申请。
- 管理员：客户分配、报价草稿/审批/发布/撤回、政策设置、审核及审计。
- 未鉴权不加载客户资料；隐藏导航不是权限控制。
- 价格卡展示适用范围、生效/截止、来源和版本；历史价用文字加状态色，不只靠颜色。
- 新报价不改写已发送报价单；报价单保存不可变价格快照与引用版本。
- 先人工选择工具/条件进行联调，明确标记“规则联调，未接入模型”，不伪造 AI 回答。
- 加载、空结果、拒绝、需补充条件、需复核、服务异常分别展示；手机宽度验证无溢出。

验收：真实浏览器完成两种角色端到端操作和越权直连测试；静态测试不能替代浏览器验收。

## 阶段四：模型与 Wiki

- 实现模型适配器，API Key 仅留后端；模型 ID、超时、调用/Token 预算可配置。
- 工具输入使用严格 Schema，限定次数、分页与时间预算；调用失败不能说“0 条”。
- Wiki 通过配置的白名单目录只读访问，记录 source_ref、内容哈希与更新时间。
- 不把 Wiki 文本指令当作系统指令，不把全部客户或内部价格送入模型。
- 产品知识可走 RAG；当前价格始终以报价服务校验结果为准。
- 需要修改和保存的动作绑定具体内容并由员工确认，加入幂等与审批后恢复。
- 准备脱敏问数、同名消歧、缺条件、注入、跨权限、知识冲突、过期价评测集。

验收：真实模型的工具选择和参数准确性、任务成功率、事实支持、耗时与成本单独报告。

## 关键报价反例

1. 4 月和 7 月同范围均批准且生效：选择 7 月版本。
2. 7 月是草稿或未来版本：不能提前替代当前有效版本。
3. 最新版本已过期/撤回：要求复核，不悄悄回退 4 月价格。
4. 新价属于其他客户/规格/币种/数量：不混用、不泄露。
5. 2025 年旧价：依政策要求复核；复核产生新版本，不修改原记录。
6. 同日期同修订或数量档位重叠：要求管理审核，不能任意取第一条。
7. 金额、来源、审批时间、适用条件缺失或矛盾：禁止生成当前报价。
