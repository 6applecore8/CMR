# 前端初步重构（2026-10-24）

## 目标与边界

主 Agent 独立实施。沿用原生 HTML/CSS/JavaScript 和本机 Python 服务，保留米白、墨绿的品牌方向。不更改客户数据、API 合同、草稿及每日清单的存储键，不提交或推送 GitHub。

## 实施计划

1. 缩短介绍和统计区域，将客户工作区与每日清单分为主次双栏；窄屏采用单列。
2. 统一筛选、客户卡片、详情和表单的间距及字体层级；改善长文本和键盘焦点，表单操作区保持可访问。
3. 优化搜索输入、中文输入法、可见筛选状态及渠道键盘切换。
4. 执行既有回归、语法检查、数据隔离检查；验证真实页面，分别记录通过项和环境限制。
5. 更新交接文档、日志及索引，记录错误码和安全回滚范围。

- 客户姓名优先，电话与邮箱标签准确，长产品需求可阅读。
- 搜索、筛选、渠道切换和分页顺序保持；中文输入不触发中间态重绘。
- 顶部渠道切换仍紧邻草稿箱；每日清单保留全部操作。
