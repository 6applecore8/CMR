# Resume Writing

Help the user produce a clear, credible and role-relevant resume without inventing or overstating experience.

## Workflow

1. Read the resume and target job description provided. Follow the appropriate document or PDF instructions for file work. With authorization, inspect relevant local project code, documentation, tests or Wiki. Do not export private material merely because it is readable.
2. Identify target role, seniority, actual personal contributions, employment dates, technical details and results. Ask concise questions or mark information unverified when important facts are missing.
3. Review credibility, relevance, duplicate wording, skill-to-project consistency, layout and likely interview questions before rewriting.
4. Write concrete bullets describing the actual problem, personal action, technical method and observable result. Distinguish individual and team work, prototypes, plans, tests, deployment and real business use. Describe AI assistance honestly when relevant.
5. Match job keywords only to supported experience. Do not claim a technology is used merely because a dependency exists.
6. Show the user the draft and assumptions. Create or edit a PDF or DOCX only when requested; preserve originals unless explicitly asked to edit in place.

## Evidence and Quantification

- Use numbers when a metric has a genuine source, baseline, sample size, time range and calculation. Otherwise provide specific engineering detail rather than invented numbers.
- Distinguish percentage points from relative percentage changes. Small samples and synthetic tests do not prove production impact.
- Never fabricate job titles, employers, dates, internships, customer adoption, training work, benchmark results or ownership.
- Do not attribute later personal work to an earlier internship unless the timeline and participation are confirmed.
- Label examples and placeholders clearly; do not present them as real achievements.

## Agent and AI Application Roles

Prioritize verified work on API integration, tool calling, retrieval and citations, workflow state, permissions, error handling, evaluation and business integration. Model training and distillation are not mandatory for every Agent role; describe only the depth actually performed.

For each project, help the user explain the problem, execution flow, technical choices, personal role, verification and limitations. Distinguish code from an end-to-end validated deployment.

## Privacy and External Tools

Do not upload resumes, private Wiki content, customer information, credentials or project data to GitHub or third-party services without specific authorization. Avoid private details in public handoffs.

Resume Matcher (https://github.com/srbhr/Resume-Matcher) and Reactive Resume (https://github.com/reactive-resume/reactive-resume) are optional external projects, not components of this Skill. Check data handling and terms and obtain authorization before sharing resumes or installing software.
